# Verified result snapshot

These files were generated by [GitHub Actions run 43959488539](https://github.com/haoyu020206-netizen/panda-contact-assembly/actions/runs/43959488539) from commit `8c314d8` on an Ubuntu runner with Python 3.12 and MuJoCo 4.0.1.

Committed evidence:

- `insertion.gif`: animated nominal insertion trajectory rendered from the saved MuJoCo time series;
- `scene.png`: OSMesa-rendered final nominal insertion state;
- `joint/`, `cartesian/`, `peg/`: machine-readable summaries and metric plots;
- `robustness/aggregate.json`: aggregate success and force metrics;
- `robustness/batch_summary.csv`: all eight fixed robustness scenarios.

Official Menagerie baseline evidence was generated by [GitHub Actions run 43963689044](https://github.com/haoyu020206-netizen/panda-contact-assembly/actions/runs/43963689044) from commit `f7cae0f`:

- `menagerie-scene.png`: OSMesa-rendered final insertion state with the official Panda meshes;
- `menagerie/joint/`, `menagerie/cartesian/`, `menagerie/peg/`: summaries and metric plots.

Controller comparison evidence was generated by [GitHub Actions run 43965304170](https://github.com/haoyu020206-netizen/panda-contact-assembly/actions/runs/43965304170) from commit `8b30fa0`:

- `controller-comparison/comparison.json`: complete summaries and derived force deltas;
- `controller-comparison/comparison.csv`: compact two-controller comparison table;
- `controller-comparison/comparison.png`: aligned tracking-error and contact-force traces.

Fixed-disturbance controller evidence was generated by [GitHub Actions run 44169284923](https://github.com/haoyu020206-netizen/panda-contact-assembly/actions/runs/44169284923) from commit `e172859`:

- `controller-robustness/robustness_comparison.json`: aggregate and all paired trial records;
- `controller-robustness/robustness_comparison.csv`: sixteen controller/scenario rows;
- `controller-robustness/robustness_comparison.png`: per-scenario success and force bars.

Seeded Monte Carlo evidence was generated by [GitHub Actions run 44173170765](https://github.com/haoyu020206-netizen/panda-contact-assembly/actions/runs/44173170765) from commit `f8b8a82`:

- `monte-carlo/monte_carlo_summary.json`: sampling configuration, confidence intervals, paired outcomes, and all trial records;
- `monte-carlo/monte_carlo_trials.csv`: forty controller/trial rows from twenty paired disturbances;
- `monte-carlo/monte_carlo_summary.png`: success rates with Wilson 95% intervals and force-versus-offset results.

Full per-step time-series CSV files remain downloadable from the workflow artifact. The repository does not claim that these lightweight-model forces transfer directly to hardware; they are simulation metrics for controller comparison and regression testing.
